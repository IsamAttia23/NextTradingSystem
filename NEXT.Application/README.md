# Application Layer

هذه الطبقة مخصصة لحالات الاستخدام، وDTOs، والتحقق من المدخلات، والواجهات التي تحتاجها حالات الاستخدام.

لم يتم تنفيذ الخدمات أو واجهاتها عمدًا حسب نطاق التسليم الحالي. أضفها حسب ترتيب خطة التنفيذ في `docs/IMPLEMENTATION-PLAN.md`، ولا تضع منطق الأعمال في Controllers أو Components.
