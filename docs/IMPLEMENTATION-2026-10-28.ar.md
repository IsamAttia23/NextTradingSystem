- كمية الإضافة موجبة، بدقة ثلاث منازل عشرية؛ تكلفة الوحدة غير سالبة، بدقة منزلتين عشريتين. متوسط التكلفة مرجح ومقرب إلى دقة التخزين.
- النقل يخصم المتاح فقط بعد استبعاد المحجوز، ويمنع النقل إلى المخزن نفسه أو التعامل مع منتج أو مخزن غير نشط.
- ينشأ رصيد الوجهة عند الحاجة، وتُسجَّل حركتا TransferOut وTransferIn بمرجع عملية واحد وتكلفة المصدر.
- المنتجات ذات الصلاحية تتطلب دفعة وتاريخ صلاحية غير منتهٍ عند الإضافة، وتتطلب دفعة صالحة عند النقل. تنتقل كمية الدفعة مع الرصيد، ويُرفض اختلاف تاريخ الدفعة الموجودة. تُحفظ إشارة الدفعة في ملاحظات سجل الحركة.
- يمنع OperationId إعادة تسجيل العملية؛ تعارضات التزامن والمفاتيح الفريدة تُترجم إلى HTTP 409. لا تعاد محاولة الكتابة تلقائياً بعد الفشل.
- الكميات بوحدة المنتج الأساسية؛ لم تُضف دورة فواتير أو قيود محاسبية تلقائية خارج طلب الإضافة والنقل.

## التحقق

- نقطة البداية: 31 اختباراً ناجحاً.
- النتيجة النهائية: **44 اختباراً ناجحاً، دون فشل أو اختبارات متخطاة**، في وضع Release.
- تشمل الاختبارات HTTP الفعلي مع Razor وCookies وCSRF والتفويض، وشاشات CRUD الجديدة، والنماذج العربية ذات الكميات الكسرية وتواريخ الصلاحية، والحذف، وحدود اعتماديات Controllers وعقود DTOs.
- اختبارات PostgreSQL تنشئ قاعدة منفصلة باسم عشوائي `next_tests_<guid>` لكل اختبار وتحذفها بعده. تشمل التكلفة المرجحة، منع التكرار، المحجوز، الدفعات، فشل سجل الحركة والتراجع الكامل، والنقل المتزامن دون تجاوز الرصيد.
- أمر إعادة الاختبار على PostgreSQL المحلي من PowerShell:

```powershell
$env:NEXT_RUN_POSTGRES_TESTS = '1'
# يمكن تحديد NEXT_TEST_POSTGRES؛ وإلا تُقرأ وصلة NEXTDatabase من User Secrets المحلية.
dotnet test NextTradingSystem.slnx --configuration Release --no-restore
```

بدون العلم NEXT_RUN_POSTGRES_TESTS تتخطى المجموعة اختبارات PostgreSQL التي تحتاج خادماً محلياً وصلاحية CREATE DATABASE.
